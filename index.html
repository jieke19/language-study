HSK 4급 기억 되살리기

중국어 회화 복습 4주 로드맵

4주 뒤, 여행·일상 상황에서 15문장 이상 막힘없이 말하기가 목표입니다.

진행 방식 1회 10~15분

  1. 복습 3분 — 지난 시간 문장 3개를 중국어로 말하기 (한국어 힌트만 보고)
  2. 패턴 5분 — 오늘의 패턴 5개: 한국어 → 중국어로 바로 말하기
  3. 상황 대화 5분 — 정해진 상황에서 역할 대화
  4. 정리 2분 — 틀린 것 중 3개만 골라 다시 말하기. 발음은 성조 위주로 교정

4주 로드맵

주주제핵심 패턴 예시
1주자기소개·일상·시간我平时… / 大概…左右 / 因为…所以…
2주식당·카페·쇼핑我要一个… / 可以…吗？ / 太…了
3주업무·회의·전화我想确认一下… / 什么时候方便？ / 麻烦您…
4주여행·호텔·길찾기怎么走？ / 我想预订… / 能不能帮我…

원칙

  • 병음은 처음 2주만 같이 표기, 3주차부터는 한자+소리만
  • 틀려도 끝까지 말하게 하고, 고칠 것은 세션 끝에 몰아서
  • 모르는 단어는 세션 중에 알려 주되, 대화는 끊지 않기

어휘

HSK 4급 회화 빈출 300개를 4주에 나눠 하루 15개씩. 매일 세션 끝에 그날 단어 3개로 짧은 문장 만들기(말로만).

조정 가능한 것

  • 횟수(주 3회/5회), 시간대, 세션 길이
  • 한자 읽기 비중을 늘릴지, 말하기만 할지
  • HSK 시험 대비로 돌릴지, 여행 회화로 돌릴지

영어는 같은 방식으로 IELTS·TOEFL 만점, 원어민 수준의 즉답 훈련을 목표로 삼습니다.
